# Belajar Python Dasar

Kumpulan skrip latihan Python dasar, disusun berurutan dari materi paling awal.

| File | Materi |
|---|---|
| `1_main.py` | Hello world & struktur file Python |
| `2_variable.py` | Variabel |
| `3_type_data.py` | Tipe data |
| `4_input_data.py` | Input dari user |
| `5_manipulasi_string.py` | Manipulasi string |
| `6_escape_character.py` | Escape character |
| `7_string_interpolation.py` | String interpolation (f-string) |
| `8_operator_aritmatika.py` | Operator aritmatika |
| `9_operator_asigment.py` | Operator assignment |
| `10_operator_perbandingan.py` | Operator perbandingan |
| `11_operator_logika.py` | Operator logika |
| `12_operator_string.py` | Operator string |
| `13_prioritas_operator.py` | Prioritas operator |
| `14_control_flow.py` | Control flow (if/elif/else) |
| `15_loops.py` | Perulangan (for/while) |

## Menjalankan

```bash
python3 1_main.py
```
